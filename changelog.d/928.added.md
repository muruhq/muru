Added `muructl preview [TARGET]`, which opens a one-time entry link to the preview of any release the daemon routes to, or prints it with `--print` or the `Muru-Preview` header with `--header`; `--valid-for` makes a link that lasts up to an hour and `--new-secret` gives the release a new preview secret. `muructl deploy --hold --open-preview` opens the link once the release is ready, and the MCP server has a `preview` tool.
