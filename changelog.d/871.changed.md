Changed `muructl restart --all` to one call of the admin API that the release's host carries out, where the command used to restart each worker itself. `--group NAME` no longer needs `--all`, `--cancel` ends a restart under way, and `--force` is for one worker and is refused with `--all` and `--group`. The command prints how many workers were marked and that the restart has finished, in place of a line for each worker.
