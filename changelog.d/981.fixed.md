Fixed a worker replaced while the daemon is stopped, restarting or being upgraded: the edge went on routing to the old worker's socket, so a release with one worker answered nothing until the daemon was back, and the daemon that started next could not take the release's host over, started a second one and left the first running. The host now makes the new worker reachable at the path the edge has, and the daemon asks a host it takes over which sockets its workers listen on.
