Added named deployments. A `deployment` key at the top of an applied file names a set of applications, hosts, routes and the rest that is applied, pruned and removed together; files without one, and what commands make, belong to `default`. Only its owner changes an object, a named deployment takes one from `default` by declaring it, and nothing is removed while a route of another deployment names it. `muructl deployment list` shows the deployments, `muructl deployment remove NAME` removes one as a unit, and `muructl render --deployment NAME` writes the key.
