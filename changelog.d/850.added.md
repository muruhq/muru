Added a directory of each release's own for built static files, given as `MURU_STATIC_DIR` and named `static:` in a static entry, so `collectstatic` run as a `before_fork` gate never writes into a shared source directory: `STATE/static/APP/RELEASE` under the daemon, made empty with the release and removed with it, beside the run's data directory under `muructl run`, and `staticfiles` in the project under `muructl serve` (`--static-dir`).
