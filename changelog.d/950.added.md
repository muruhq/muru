Added `muructl doctor`, which checks Muru itself: it lists every socket and file of an installation with what it is for, who owns it and its condition, checks the registry, the locks, the paths, the store and the releases against the processes that run, and names the command that puts a failure right. `muructl doctor store` checks the state store read-only, with `--dump-schema` to print its schema and `--copy FILE` to take a consistent copy while the daemon runs. Both read and never change anything, work with no daemon, exit 1 when a check fails and take `--json`.
