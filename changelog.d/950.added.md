Added `muructl doctor`, which checks Muru itself: it lists every socket and file of an installation with what it is for, who owns it and its condition, checks the registry, the locks, the paths, the store, the releases, the edge, the versions and the disk against one another, and names the command that puts a failure right. `muructl doctor store` checks the state store read-only, with `--dump-schema` to print its schema and `--copy FILE` to take a consistent copy while the daemon runs, and `muructl doctor timeline` merges the last events, the daemon's last log lines and each process's start in order. All read and never change anything, work with no daemon, and take `--json`; the first two exit 1 when a check fails. `muructl debug bundle` carries what doctor finds, which `muructl doctor --bundle FILE` prints on another machine, and the MCP tool `doctor` runs it for an agent.
