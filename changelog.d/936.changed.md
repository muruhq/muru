`muructl apply --prune` now reaches only the deployments the files name, and `--prune=all` every deployment, `default` among them; the same goes for `--prune` beside `--apply` at start. For a node whose files name no deployment, `--prune` leaves any named deployment alone. `muructl app set` and `muructl app unset` are refused on an application a named deployment owns, and warn when applied files wrote the application's settings last.
