Added a `release.loaded` event when a release's host has imported the application, giving how long it took and, with `import_report` on, the import report's headline figures; and the metrics `muru_release_load_seconds`, `muru_worker_load_seconds` (a worker that imported the application itself), and `muru_worker_modules_loaded_total` and `muru_worker_module_load_seconds_total` for the modules each worker has loaded for the first time since the fork.
