Added `muructl instance list`, which lists every Muru instance on the machine, daemons, development runs and serves, from the instance registry, each `running`, `detached` or `stale` with its pid, uptime, listeners, dashboard and where it works from, and with `--orphans` the Muru processes no live instance accounts for, exiting 1 when there are any; `--label`, `--kind`, `--all-users` and `--json` narrow and shape it, the read-only MCP tool `instances` returns it, and `muructl status` with nothing listening says how many instances it shows.
