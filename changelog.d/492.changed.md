A managed HTTP server's instances now run under a log relay each, so their lines carry the time and a tag naming the instance and stream (`muru.instance[0]:`, `muru.instance[0].stdout:`), the release's log is rotated and reopened without losing lines (no `copytruncate` is needed under `rotate = 'external'`), and an instance that exits while no daemon runs is reported with its real exit status.
