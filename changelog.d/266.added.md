Added gates: `before_fork = true` on a declared command runs it as a release starts, once its host has preloaded and before any worker forks, failing the start if it fails, and `before_promote = true` runs it just before a rollout or blue/green promotion moves all traffic, stopping the promotion if it fails. A gate runs once a release unless `every_start = true`, needs a `timeout`, is always exclusive, runs under the daemon only, and `muructl release show` lists the gates a release has passed.
