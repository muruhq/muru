A port another instance of Muru's holds is named as that instance when a bind fails, in `muructl run`, `muructl serve`, the daemon's listeners and a dashboard's address, `port 8000 on 127.0.0.1 is in use by the development run of shop in ~/src/shop (pid 4123, dashboard http://127.0.0.1:8001/)`, before falling back to lsof or ss, `muructl daemon start` refuses an address a running instance holds before it starts anything, and `muructl instance list --ports` lists the ports every instance uses or is configured to use, with the clashes between them.
