Added the deployment of each object to `muructl app list`, `host list`, `route list`, `upstream list` and `overlay list`: a DEPLOYMENT column once any object belongs to a named deployment, `--deployment NAME` to list one deployment's, and `deployment` in their JSON and the admin API. `muructl deployment show NAME` prints one deployment as its files would state it, and `muructl deployment remove NAME --data` removes the data directories of the applications it removes, listed with their sizes before it asks.
