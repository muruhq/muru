Commands that talk to a daemon reach a named instance by `--instance NAME`, by `MURU_INSTANCE`, or by `instance = "NAME"` in the checkout's `muru.local.toml`, a key of that file alone, with no machine-wide current instance; a development run of the checkout still answers first what it can, saying so, a change sent to a named instance says where it went, `muru: deploying shop to instance dev (from muru.local.toml)`, with an `instance` field in `--json` output, `muructl mcp serve` settles its instance once at start, and the commands that work only on this machine's processes and files say so for an instance that is not on it.
