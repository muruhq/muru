A release is previewed only with its preview secret: the `Muru-Preview` header and the `muru_preview` cookie carry `RELEASE.SECRET`, a release's ID alone previews nothing, and every preview that is not honoured is answered alike, with `muru-preview: ignored`. The edge removes the header and the cookie from requests before an application or an upstream sees them, and the secret is in no listing, event, log, bundle or copy of the state store.
