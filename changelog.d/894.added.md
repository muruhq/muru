Added `muructl daemon config`, for the daemon's own configuration file: `path` prints where it is, `show` prints it (with `--full`, every setting with its default), `check [FILE]` says whether the daemon would take it, and `set`, `unset`, `edit` and `replace` change it, each checking the result before the file is written and then having the running daemon reload. A reload now says which settings read only at start the file has changed since the daemon started.
