Added `muructl detour run`, development mode served through a local daemon's edge as a release of kind `detour` of the application, for as long as it runs: reload, the toolbar, tracebacks and `--single` work as under `muructl run`, the run serves on a Unix socket in its own directory with no port, it opens its detour again when the daemon restarts, and Ctrl-C ends it. The `[run]` table is read as `muructl run` reads it, its listener, TLS, `hosts` and `compression` keys not used.
