An instance that ran for more than three days on macOS disappeared from `muructl instance list` and lost its lock, its pid file and the records a restarted daemon takes its edge and releases over from, because macOS deletes untouched files under `/tmp` by age. The run directory now holds sockets and nothing else: every file a running daemon or `muructl run` keeps is in `run` under the state directory, and the registry of running instances is in the state location under your home directory. A release whose application name and release ID were long no longer fails to start for a socket path over the platform's limit: a host's sockets are in a directory named by the release's number, and no socket's path carries a name.
