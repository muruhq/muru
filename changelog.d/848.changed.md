A path hint (`X-Muru-Sendfile`, or `X-Sendfile` in compatibility mode) from an application Muru's workers serve is now opened by the worker as the application's user, within the mount's `sendfile_roots`, and handed to the edge open, so the edge's user needs no access to the file and one written `0600` is served; it keeps Range, conditional requests, ETag, Last-Modified and HEAD, and now gets a precompressed `.br`, `.zst` or `.gz` variant beside the file as a static route does.
