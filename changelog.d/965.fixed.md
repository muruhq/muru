Fixed the events a release's host raises while the daemon is stopped, restarting or being upgraded, which were lost: the host now holds the last 256 and sends them to the daemon that takes it over, which records each with the time it happened, counts it in the metrics and delivers it to the sinks, and a `host.events_dropped` warning says how many were dropped past that. The `worker.started` and `worker.ready` events of a release's first workers, raised before the daemon had connected, are recorded as well.
