Added named daemon instances: `muructl instance create NAME --listen ADDRESS` defines one in the configuration area, with an `instance.toml` and its own `muru.toml`, `--instance NAME` or `MURU_INSTANCE` on the daemon's commands puts every location under `instances/NAME` so `muructl daemon start --instance dev` needs nothing else, `muructl instance list` shows a defined instance that is not running as `stopped`, `muructl instance remove` removes one, with `--state` its state and logs too, and a systemd template unit, `muru@.service`, runs one by name.
