Added detached command runs: `muructl command run APP NAME --detach` and `muructl exec APP --detach -- ...` start a run that outlives its caller and a daemon restart or upgrade, and `muructl command runs`, `status`, `logs` (with `--follow`) and `stop` list, show, follow and stop runs. The daemon keeps the last 20 runs of each command (`[daemon] keep_command_runs`), each with its output in a file of its own, and an exclusive command's claim now survives a daemon restart.
