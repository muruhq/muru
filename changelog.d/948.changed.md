The layout of the run directory and where the daemon's runtime files are changed, with nothing carried over. Stop a daemon of an earlier version with `muructl daemon stop --shutdown` before starting this one: `muructl daemon upgrade` refuses to upgrade it in place, and a daemon refuses to start beside an edge or releases an earlier version left running. An instance still running under an earlier version is not listed by `muructl instance list`. `muructl release show` prints the release's `number`, a named worker group's sockets are named by the group's place instead of its name, `muructl run` writes its pid file under the state location, and the state store's schema version is 22.
