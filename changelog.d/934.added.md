Added `--apply FILE or DIR` to `muructl daemon start`, `muructl daemon run` and `muructl up`, with `--prune` beside it: the files are applied once the daemon is up, at every start and to a daemon that is already running, and the daemon reports ready only when they are applied. With nothing running the daemon starts what it had before it applies, saying first what the apply will change. A start whose files cannot be applied fails, leaving what was serving as it was.
