The daemon's configuration file and the files `muructl apply` reads each refuse the other's tables. A daemon does not start or reload with an application, host, route, upstream or overlay in its file, which it read and ignored without a word, and an apply fails on a table of the daemon's own configuration, such as `[[listener]]` or `[limits]`, which it skipped with a warning or none. An applied condition with the name of one the daemon's file defines is refused, as a client class or a rate limit is. The configuration reference has a page and a JSON Schema for each file, `deployment.schema.json` for applied files.
