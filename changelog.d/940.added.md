Added `muructl daemon restart`, which re-executes the daemon in place from the `muructl` it runs so that the settings read only at start take effect: hosts and the edge keep serving, the daemon keeps its pid, a service manager sees a reload, and the files of `--apply` are not applied again. It is refused when the installed `muructl` is of another version, which `muructl daemon upgrade` is for. `muructl daemon config set`, `unset`, `edit` and `replace` take `--restart`, which restarts the daemon when the change needs it, and a reload's JSON lists the settings that wait for a restart as `stale`.
