Added an application data directory shared by every release, given to the release's host, workers and commands as `MURU_DATA_DIR`, with a media part (`MURU_MEDIA_DIR`), a file hint root of every mount and named `media:` in `sendfile_roots` and static entries, and an uploads part (`MURU_UPLOADS_DIR`), never served and where `upload.save()` now puts a file by default. It is `STATE/data/APP` under the daemon (`[app.NAME] data_dir`, `media_dir` and `uploads_dir` move it), `runs/NAME-HASH/data` in the user state directory under `muructl run` (`--data-dir`), and a volume named with `--data-dir` under `muructl serve`; `muructl data show`, `muructl data check` and `muructl status --app` report it, and `muructl app remove --data` removes it.
