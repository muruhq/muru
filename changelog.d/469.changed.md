Muru no longer guesses which application takes the requests when no hosts are declared. One application serving takes every request. An action that would make a second application serve with no hosts is refused, with a host and a route for each application to paste, and `--hold` still works. If several applications serve with no hosts anyway, every request is answered 421 with the reason `no_host`, with a `routing.no_host` event and a line in `muructl status`. The stored default application is gone.
