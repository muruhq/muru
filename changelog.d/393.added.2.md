Added a state for each instance of a managed HTTP server release (`running`, `starting`, `backoff`, `exited` or `failed`), shown by `muructl release show` with when an instance in `backoff` is started next, the `server.crash_looping` event for an instance that has exited three times in a row soon after starting, the `server.gave_up` event for one left failed by `give_up_after`, and the `muru_server_exits_total` counter of instance exits by outcome.
