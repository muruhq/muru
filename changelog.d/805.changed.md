A development run keeps its admin socket, its `pid` file and its releases' run directories in a directory of its own named by its instance ID, `RUNTIME/run-7f3a9c2e`, in place of `RUNTIME/runs/PORT` and a directory under the temporary directory, and `run.json` is gone: commands find runs through the instance registry, so a run killed outright is never reached, and two runs on one port on different addresses no longer collide.
