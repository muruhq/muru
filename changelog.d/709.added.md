The development toolbar has a **Hints** panel, the first of a record's panels, listing what stands out: a statement or an outbound endpoint repeated (N+1), a slow query or call, an HTML or JSON response that went out uncompressed, the event loop held, long waits for a worker or a thread, garbage collection, and an answer of Muru's own with the setting behind it. The badge counts the hints, and `muructl debug request` and the record's JSON carry them.
