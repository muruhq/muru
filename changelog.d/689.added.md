Added overlays triggered by a named condition: `trigger = { condition = 'NAME' }` keeps an overlay active while the condition is firing and ends it once it resolves, held as it is while the condition is unknown, with `min_active`, `cooldown` and `max_per_hour` against flapping, `latch = true` to keep it until ended by hand, and `preconditions.probe`, a path the `release_ready` release must answer before activation. `muructl overlay list` and `preview` show the condition's state and figures.
