Every Muru instance on a machine, a daemon, a `muructl run` or a `muructl serve`, registers itself in one registry per user, in `registry` in the user's default runtime location whatever its run directory, with one entry each that only its owner writes and that is live while its owner holds a lock on it. A daemon keeps its instance ID in its state directory, `muructl status --json` reports the ID and the hostname, and `muructl cache` reads what each live instance uses from its entry.
