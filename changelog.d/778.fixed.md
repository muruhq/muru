The configuration reference and the error pages, overlays and client classes guides now state one rule for paths: a relative path in a file given to `muructl apply` is taken from that file's directory, and a release's own static directories and error pages from its source directory. `muructl apply` now does the same for an upstream's and a mount's `sendfile_roots` and a client class's `ja4_list`, which it sent as written.
