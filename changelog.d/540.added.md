Added `muructl debug report`, a short summary of an installation to attach to a bug report, as text, Markdown (`--format markdown`) or JSON. It is safe to post: it holds no logs, request data, environment or secrets, and replaces application names, host names, paths and addresses with placeholders. It works with no daemon running, and against `muructl run` and `muructl serve`, where `muructl config show --effective` now lists the settings in force too.
