Under the daemon, a release's host, workers, commands and managed servers now start from a clean environment: what Muru sets, a small base from the daemon's own environment, the variables `[daemon] pass_env` names, and what the release declares. A release relying on a variable it inherited from the daemon's environment must now declare it or have the daemon's file pass it through. `muructl run` and `muructl serve` keep the environment they were started with.
