Added schedules for declared commands: `schedule = { cron = "30 3 * * *", timezone = "Australia/Sydney" }` runs the command under the daemon at those times with the application's current release, and `schedule = { at_boot = true }` when the daemon starts from nothing. A scheduled command needs a `timeout`, a run due while one is under way is skipped with a `command.skipped` event, each scheduled run is a detached run with the trigger `schedule`, and `muructl command list` shows each schedule and its next run.
