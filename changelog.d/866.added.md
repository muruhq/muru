Added release metadata: `muructl deploy` records the commit, the branch or tag, and whether the checkout had changes when the source is a git checkout, and `--metadata KEY=VALUE` records more, such as `url` and `description`. `release list` shows the commit, `release show`, `--json`, the dashboard and the `release.created` event show the rest, and `config export` writes it as a release table's `metadata`.
